# Крестики-Нолики — T04

Многопользовательская игра «крестики-нолики» на Flask + PostgreSQL + SQLAlchemy с авторизацией.

## Структура

```
tictactoe/
├── main.py
├── requirements.txt
├── domain/                          # бизнес-логика, без зависимостей от БД и веба
│   ├── model/                       # Game, GameBoard, GameState, User, SignUpRequest
│   └── service/                     # интерфейс сервиса, минимакс, UserService, AuthService
├── datasource/                      # слой работы с данными
│   ├── database.py                  # подключение PostgreSQL + SQLAlchemy
│   ├── model/                       # GameDS, UserDS (с Mapped[...] аннотациями)
│   ├── mapper/                      # GameMapper, UserMapper (domain <-> ds)
│   ├── repository/                  # GameRepository, UserRepository
│   └── service/                     # GameServiceImpl — единственная реализация интерфейса
├── web/                             # слой взаимодействия с клиентом
│   ├── model/                       # GameWeb, GameBoardWeb
│   ├── mapper/                      # GameWebMapper (domain -> web)
│   ├── module/                      # UserAuthenticator
│   ├── route/                       # auth/game/user контроллеры
│   └── static/                      # HTML + CSS + JS
└── di/
    └── container.py                 # граф зависимостей
```

## Подготовка БД (PostgreSQL)

```bash
sudo -u postgres psql -c "DROP DATABASE IF EXISTS tictactoe_db;"
sudo -u postgres psql -c "CREATE USER myuser WITH PASSWORD 'mypassword';" || true
sudo -u postgres psql -c "CREATE DATABASE tictactoe_db OWNER myuser;"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE tictactoe_db TO myuser;"
sudo -u postgres psql -d tictactoe_db -c "GRANT ALL ON SCHEMA public TO myuser;"
```

Таблицы (`games`, `users`) создадутся автоматически при первом запуске.

## Установка и запуск

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

Открыть: http://127.0.0.1:5000

## Эндпоинты

| Метод  | URL                       | Авторизация | Описание |
|--------|---------------------------|-------------|----------|
| POST   | /auth/register            | нет         | регистрация (body: login, password) |
| POST   | /auth/login               | Basic       | авторизация (заголовок Basic base64(login:password)) |
| POST   | /games                    | да          | создать игру (body: opponent_type = computer/user) |
| GET    | /games                    | да          | список доступных игр (state=waiting) |
| POST   | /games/{id}/join          | да          | присоединиться к игре |
| GET    | /games/{id}               | да          | получить игру |
| PATCH  | /games/{id}               | да          | сделать ход (body: row, col) |
| GET    | /users/{uuid}             | да          | информация о пользователе |
